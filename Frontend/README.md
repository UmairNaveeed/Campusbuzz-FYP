# CampusBuzz React Application

React.js application built with Tailwind CSS, matching the Figma design exactly.

## Installation

```bash
npm install
```

## Development

```bash
npm start
```

## Build

```bash
npm run build
```

## Project Structure

```
src/
  ├── App.jsx              # Main application component
  ├── components/
  │   ├── Sidebar.jsx      # Left sidebar navigation
  │   ├── MainContent.jsx  # Main feed content
  │   ├── RightSidebar.jsx # Right sidebar widgets
  │   └── TweetCard.jsx    # Reusable tweet component
  ├── index.js             # React entry point
  └── index.css            # Tailwind imports
```

## Technologies

- React 18.2.0
- Tailwind CSS 3.3.0
- All styling via Tailwind utility classes
